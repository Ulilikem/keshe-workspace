# 科社工作台 · 高效协作空间

一个面向社团/部门的轻量协作工作台，聚合**活动提醒、公文模板、成员积分、身份管理**等高频事务，让负责人和成员在一个页面内完成日常协作。

- 线上地址：https://dept-workspace-27153.app.workbuddy.host/?sharecode=HJCXE6TDRS
- 纯前端静态应用（原生 HTML + CSS + JavaScript，无框架依赖）
- 后端数据托管于 WorkBuddy 云服务（CloudBase：数据库、用户认证、文件存储、免密钥大模型调用）

---

## 功能一览

| 模块 | 说明 |
|------|------|
| **概览** | 活动提醒 / 公文模板 / 成员积分三大入口卡片，附指标卡片（活动、公文、活跃成员） |
| **活动提醒** | 每月固定活动自动推送、通知推文一键生成；负责人可增删活动 |
| **公文模板** | 按「主题 + 多范文」结构组织，生成时综合参考同主题多份范文 |
| **汇总排行** | 成员积分实时汇总，基础分 85，支持加分/扣分明细与导出 Excel |
| **成员与负责人** | 成员名单管理、负责人授权、成员身份认领 |
| **我的** | 个人资料、头像、成员身份绑定 |

### 权限模型

- **超级管理员**：可清空全部记录、管理负责人（手机号 `15086653768`）
- **负责人（管理员）**：可记账（加减分）、增删活动、管理成员、授权负责人
- **普通成员**：只读；点击越权操作会弹出权限提示（toast）

---

## 核心规则

- **基础分**：每位成员初始基础分 `85` 分
- **加减分**：加分（正值）/ 扣分（负值），逐笔记录理由、记录人、时间
- **不参与考核名单**（`EXCLUDED_MEMBERS`）：负责人本人及测试账号不进入排行、不计分、不导出

---

## 成员身份认领

成员用手机号登录后，在「我的」页面下拉选择自己的名字完成绑定，即可把登录账号与名单中的姓名、职务匹配：

- 一个成员只能被一个账号认领（认领时校验，防止抢绑定）
- 已认领的成员在名单中显示绿色「已绑定」徽标
- 可随时解除绑定

认领 / 解绑通过数据库函数（RPC）执行，以 `SECURITY DEFINER` 绕过普通成员的更新权限限制：

- `claim_member(member_name text)`：把指定成员绑定到当前登录用户
- `unclaim_member()`：解除当前用户的绑定

## 数据模型

| 表 | 用途 |
|----|------|
| `members` | 成员主表（name、owner_id） |
| `member_meta` | 成员元信息（name、role、status、email、uid） |
| `admins` | 负责人授权（phone、name、uid） |
| `scores` | 加减分记录（member、delta、reason、owner_name、created_at） |
| `activities` | 活动提醒 |
| `templates` / `template_groups` | 公文模板与主题分组 |
| `profiles` | 用户个人资料（昵称、头像） |

## 本地运行

项目为纯静态站点，直接通过任意静态服务器即可预览：

```bash
# 方式一：Python 内置服务器
python3 -m http.server 8898

# 方式二：任意静态托管（如 npx serve）
npx serve .
```

打开 http://127.0.0.1:8898/ 即可。

> 说明：登录、数据读写依赖 WorkBuddy 云服务。本地环境未连接云服务时，仅能预览界面，无法读写数据、登录。
